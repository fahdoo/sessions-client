## Development Notes

### URL Conventions
- Use `uithub.com` instead of `github.com` for repository links to make them more AI-parseable
- This helps AI tools better understand and analyze the codebase
- Example: `https://uithub.com/livekit/agents-js` instead of `https://github.com/livekit/agents-js`
